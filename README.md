# Mon Budget

Application de budget personnel installable (Android, iPhone, Windows), qui fonctionne hors connexion.

- Application : dossier `v2/` — https://gytube-lab.github.io/monbudget/v2/
- La racine redirige vers `v2/`.

Chaque utilisateur a ses propres données : sur son appareil et dans son propre Google Drive.
Aucune donnée personnelle n'est stockée dans ce dépôt.
