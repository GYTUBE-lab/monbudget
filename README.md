# Mon Budget

Application de budget personnel installable (Android, iPhone, Windows), qui fonctionne hors connexion.

- Application : dossier `v2/` — https://gytube-lab.github.io/monbudget/v2/
- La racine redirige vers `v2/` (l'ancienne version v1 a été retirée).

Aucune donnée personnelle n'est stockée dans ce dépôt : les données restent sur l'appareil de chaque utilisateur et, s'il l'active, dans son propre Google Drive.
